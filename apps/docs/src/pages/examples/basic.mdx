# Basic Example

The runnable source lives in the
[basic example](https://github.com/ohtools/ohtools/tree/main/examples/basic).
It defines a plugin, composes an app, explores a tool, runs it, and registers
MCP exposure.

Run the local smoke path with Bun:

```sh
bun run --cwd examples/basic smoke
```
