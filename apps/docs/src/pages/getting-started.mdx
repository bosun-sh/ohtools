# Getting Started

Ohtools 0.1.0 supports Bun only. Node, Deno, browser runtimes, HTTP transport,
SSE, and streamable HTTP are not supported in this release.

```sh
npx @bosun-sh/ohtools create my-tools
cd my-tools
bun install
bun run ohtools:list
```

The scaffold creates `src/ohtools.ts`, runnable package scripts, and a local
`.agents/skills/ohtools` skill so agents can discover Ohtools project guidance.

To add Ohtools to an existing Bun TypeScript project instead:

```sh
npx @bosun-sh/ohtools init
```

Manual setup is also supported:

```sh
bun add @bosun-sh/ohtools effect @modelcontextprotocol/sdk
```

Create `src/ohtools.ts`:

```ts
import { Ohtools, jsonSchema } from "@bosun-sh/ohtools";

export default new Ohtools().tool("hello", {
  description: "Return a greeting.",
  input: jsonSchema<{ name: string }>({
    type: "object",
    properties: { name: { type: "string" } },
    required: ["name"]
  }),
  run: ({ name }) => ({ message: `Hello, ${name}` })
});
```

Run it through the Bun-backed CLI adapter:

```sh
bunx ohtools --app ./src/ohtools.ts list
bunx ohtools --app ./src/ohtools.ts run hello --input '{"name":"Ada"}'
```

Use `/guides/first-tool` for a smaller tool walkthrough, `/concepts/app` for
the app model, and `/adapters/mcp` when you are ready to expose the app over MCP
stdio.
